# @knorby/drugcentral-client

A fully-typed, zero-dependency TypeScript client for the [DrugCentral](https://drugcentral.org) API — universal: Node, React Native, browsers, Bun, and Deno.

Status: pre-release, under active development. Full documentation (capability
matrix, guided usage, configuration, disclaimers) lands with the first
release.

Data credits and licensing: DrugCentral (University of New Mexico) is the data
source; its database is licensed CC BY-SA 4.0. This library's code is
Apache-2.0 and is not affiliated with DrugCentral or the University of New
Mexico. Nothing in this library or its returned data is medical advice.
